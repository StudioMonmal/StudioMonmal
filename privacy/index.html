1. 개요

Studio Monmal이 제공하는 회선알라미는 사용자가 여러 이동통신 회선, 일정, 요금제, USIM/eSIM, 기기, 혜택 등의 정보를 직접 관리할 수 있도록 제공되는 Android 애플리케이션입니다.

회선알라미는 별도의 회원가입 시스템이나 Studio Monmal이 운영하는 사용자 계정 서버를 사용하지 않습니다. 사용자가 앱에 입력한 데이터는 원칙적으로 사용자의 기기 내부에서 처리되고 저장됩니다.

3. Studio Monmal 자체 서버를 통한 수집

회선알라미는 사용자의 전화번호, 회선 정보, 일정, 요금제, 첨부파일 또는 기타 앱 데이터를 Studio Monmal이 운영하는 별도의 서버로 수집하거나 저장하지 않습니다.

현재 회선알라미에는 다음 기능이 포함되어 있지 않습니다.

  • 광고 SDK
  • 사용자 행동 분석 SDK
  • 광고 추적 시스템
  • Studio Monmal 자체 사용자 계정 서버
  • Studio Monmal 자체 클라우드 동기화 서버

4. Telegram 알림 및 외부 전송

Telegram 알림은 선택적인 유료 기능이며, 사용자가 직접 기능을 설정하고 활성화한 경우에만 사용됩니다.

사용자는 자신이 생성하거나 관리하는 Telegram Bot의 Bot Token과 Chat ID를 직접 입력해야 합니다.

Telegram 알림이 활성화되면 알림 제공을 위해 다음 정보가 Telegram 서비스로 전송될 수 있습니다.

  • 일정 또는 혜택 알림 제목
  • 관련 회선의 전화번호
  • 일정 날짜 및 알림 내용
  • 혜택 이름 및 관련 금액
수신 서비스 목적 전송 방식
Telegram 사용자가 설정한 Telegram Bot 대화방으로 알림 전달 Telegram Bot API를 통한 HTTPS 통신

Telegram은 Studio Monmal과 별개의 제3자 서비스입니다. Telegram으로 전송된 정보의 처리, 저장 위치 및 보유기간에는 Telegram의 개인정보처리방침과 서비스 정책이 적용됩니다.

Telegram 서비스의 시스템 또는 서버가 대한민국 외 지역에서 운영될 수 있으므로, Telegram 기능을 사용하는 경우 정보가 국외에서 처리될 수 있습니다. 구체적인 처리 지역과 보유기간은 Telegram의 현재 서비스 운영 및 정책에 따릅니다.

사용자는 Telegram 기능을 사용하지 않거나 앱 내 Telegram 기능을 비활성화함으로써 향후 해당 기능을 통한 정보 전송을 중단할 수 있습니다.

이미 Telegram으로 전송된 메시지는 회선알라미에서 기능을 비활성화하거나 앱을 삭제하더라도 자동으로 삭제되지 않습니다.

Studio Monmal은 Telegram으로 전송된 메시지를 Studio Monmal의 자체 서버에 별도로 복사하거나 저장하지 않습니다.

5. Telegram 인증정보 보관

사용자가 입력한 Telegram Bot Token과 Chat ID는 회선알라미의 앱 전용 로컬 저장공간에 저장됩니다.

해당 정보는 다른 일반 앱 데이터와 마찬가지로 Android의 앱별 저장공간 및 운영체제 보안 구조의 보호를 받습니다.

Bot Token과 Chat ID는 사용자가 생성하는 암호화 통합백업에 포함될 수 있으므로, 백업 파일과 백업 비밀번호를 안전하게 관리해야 합니다.

6. 첨부파일

사용자가 선택한 이미지, PDF 또는 문서는 회선알라미의 앱 전용 내부 저장공간에 복사되어 관리될 수 있습니다.

회선알라미는 Android의 Photo Picker 및 시스템 파일 선택 기능을 사용하며, 사용자의 전체 저장공간에 대한 광범위한 접근 권한을 요구하지 않습니다.

7. 백업 및 복원

사용자는 회선알라미의 통합 백업 기능을 이용하여 앱 데이터와 첨부파일을 직접 내보낼 수 있습니다.

백업에는 다음 정보가 포함될 수 있습니다.

  • 회선 및 전화번호 이력
  • 가입 및 요금제 이력
  • USIM/eSIM 및 기기 정보
  • 일정 및 혜택 정보
  • 메모와 첨부파일
  • 앱 설정
  • Telegram 설정 및 Bot Token, Chat ID

통합 백업 파일은 사용자가 지정한 비밀번호를 기반으로 AES-256-GCM 방식으로 암호화됩니다.

백업 저장 위치는 사용자가 Android 시스템 파일 선택 화면에서 직접 선택합니다. Google Drive 등 외부 저장소 제공자를 선택한 경우 해당 서비스 제공자의 개인정보 및 보안 정책도 적용됩니다.

Studio Monmal은 사용자가 내보낸 백업 파일을 자체 서버에 저장하지 않습니다.

8. Google Play 결제

회선알라미는 일부 기능을 Google Play의 비소비성 1회성 인앱상품으로 제공합니다.

결제 및 결제수단 정보는 Google Play가 직접 처리합니다. Studio Monmal은 사용자의 신용카드 번호 또는 Google Play 결제수단 정보를 직접 수집하거나 저장하지 않습니다.

회선알라미는 구매 기능의 사용 가능 여부를 확인하기 위해 Google Play가 제공하는 상품 소유 및 구매 상태 정보를 확인할 수 있습니다.

회선알라미의 일반 통합백업에는 구매 권한 자체를 저장하지 않습니다. 구매 상품의 소유 여부는 Google Play 계정의 구매 상태를 기준으로 확인합니다.

9. 보안조치

Studio Monmal은 앱이 처리하는 데이터의 보호를 위해 현재 앱 구조에서 다음과 같은 조치를 적용하고 있습니다.

  • 일반 앱 데이터 및 첨부파일을 앱 전용 내부 저장공간에 보관
  • 사용자의 전체 저장공간에 대한 광범위한 접근 권한을 사용하지 않음
  • 통합 백업 파일에 AES-256-GCM 암호화 적용
  • 백업 비밀번호를 기반으로 한 키 파생 처리
  • Telegram API 통신 시 HTTPS 사용
  • Studio Monmal 자체 데이터 수집 서버를 운영하지 않음
  • 광고 및 행동 분석 SDK를 사용하지 않음
인터넷 또는 전자적 저장 방식은 절대적인 보안을 보장할 수 없습니다. 사용자는 기기의 화면 잠금, Google 계정 보안, Telegram Bot Token 및 백업 비밀번호를 안전하게 관리해야 합니다.

10. Android 권한

회선알라미는 기능 제공을 위해 다음 Android 권한을 사용할 수 있습니다.

  • 알림 표시를 위한 권한
  • 정확한 일정 알림 예약을 위한 알람 관련 권한
  • 기기 재부팅 또는 시간 변경 이후 알림 재예약을 위한 권한
  • Telegram Bot API 통신을 위한 인터넷 접근

회선알라미는 다른 앱의 알림을 읽기 위한 Notification Listener 권한을 사용하지 않습니다.

SMS 또는 MMS 메시지를 읽기 위한 권한도 사용하지 않습니다.

11. 데이터 보유기간

사용자가 앱에 직접 저장한 정보는 사용자가 직접 삭제하거나, 회선알라미 앱 데이터가 삭제되거나, 앱이 제거될 때까지 기기 내부에 보관될 수 있습니다.

Studio Monmal은 해당 데이터를 자체 서버에 보유하지 않으므로 Studio Monmal 서버에서 별도의 보유기간을 운영하지 않습니다.

사용자가 외부로 내보낸 백업파일은 사용자가 직접 삭제할 때까지 선택한 저장 위치에 남을 수 있습니다.

Telegram으로 전송된 정보의 보유기간과 삭제 방식은 Telegram 서비스의 정책 및 사용자의 Telegram 관리 방식에 따릅니다.

Google Play 구매정보의 보유 및 결제 관련 처리는 Google의 정책에 따릅니다.

12. 데이터 삭제

사용자는 앱에서 제공되는 수정 또는 삭제 기능을 이용해 앱 내부 데이터를 직접 관리할 수 있습니다.

앱을 제거하거나 Android 설정에서 앱 데이터를 삭제하면 회선알라미의 로컬 데이터는 Android의 일반적인 앱 데이터 삭제 방식에 따라 제거됩니다.

다음 정보는 앱 삭제만으로 자동 삭제되지 않을 수 있습니다.

  • 사용자가 외부 저장 위치로 내보낸 백업파일
  • 이미 Telegram으로 전송된 메시지
  • Google Play가 관리하는 구매기록

해당 데이터는 각각 사용자가 선택한 외부 저장소, Telegram 및 Google Play에서 관리해야 합니다.

1. Overview

Line Reminder, provided by Studio Monmal, is an Android application designed to help users manage multiple mobile lines, schedules, mobile plans, USIM/eSIM information, devices, and related benefits.

Line Reminder does not operate its own user account system or a user account server operated by Studio Monmal. Data entered into the app is generally processed and stored locally on the user's device.

2. Information Processed by the App

Users may directly enter or select information including:

  • Phone numbers and mobile line information
  • Carrier and mobile plan information
  • Activation dates, porting dates, retention periods, and schedules
  • USIM/eSIM information
  • Device and SIM assignment information
  • Payment-method management information entered by the user
  • Promotions and benefit information
  • User-created notes
  • Images, PDFs, and documents selected by the user
  • Telegram Bot Token and Chat ID when Telegram notifications are used

This information is generally processed locally on the user's device for application functionality.

3. Collection by Studio Monmal Servers

Line Reminder does not transmit or store users' phone numbers, mobile line information, schedules, plans, or attachments on servers operated by Studio Monmal.

The application currently does not contain:

  • Advertising SDKs
  • Behavioral analytics SDKs
  • Advertising tracking systems
  • A Studio Monmal user account server
  • A Studio Monmal cloud synchronization server

4. Telegram Notifications and External Transmission

Telegram notifications are an optional paid feature and are used only when the user explicitly configures and enables the feature.

Users must provide the Bot Token and Chat ID of a Telegram bot they create or manage.

When enabled, information sent to Telegram may include:

  • Schedule or benefit notification titles
  • Related phone numbers
  • Dates and notification details
  • Benefit names and related monetary amounts

The information is transmitted to Telegram using the Telegram Bot API over HTTPS.

Telegram is a third-party service independent from Studio Monmal. Information transmitted to Telegram is subject to Telegram's own privacy policy and terms of service.

Telegram systems or servers may operate outside the Republic of Korea. When users enable Telegram notifications, related information may therefore be processed outside Korea according to Telegram's current infrastructure and policies.

Users can stop future transmissions through Line Reminder by disabling the Telegram feature. Messages already delivered to Telegram are not automatically deleted.

Studio Monmal does not separately copy or store Telegram messages on its own servers.

5. Telegram Credentials

Telegram Bot Token and Chat ID values entered by users are stored in application-private local storage on the user's device.

These values may be included in encrypted integrated backup files created by the user. Users should protect their Bot Tokens, backup files, and backup passwords.

6. Attachments

Images, PDFs, and documents selected by users may be copied to application-private internal storage.

Line Reminder uses Android system file pickers and the Photo Picker and does not request broad access to all files on the user's device.

7. Backup and Restore

Users may export their application data using Line Reminder's integrated backup function.

Backup files may include mobile line data, schedules, settings, attachments, and Telegram configuration, including the Bot Token and Chat ID.

Integrated backup files are encrypted using AES-256-GCM with a password supplied by the user.

Users select the destination using Android's system file picker. If an external provider such as Google Drive is selected, that provider's privacy and security policies also apply.

Studio Monmal does not upload or retain these backup files on its own servers.

8. Google Play Purchases

Line Reminder may provide certain features through non-consumable, one-time Google Play in-app purchases.

Payments and payment-method information are processed directly by Google Play. Studio Monmal does not directly collect or store users' credit card numbers or Google Play payment-method details.

Line Reminder may check product ownership and purchase-status information provided by Google Play to determine whether purchased functionality is available.

Purchase entitlements are not included in normal Line Reminder backups. Ownership is determined using information associated with the relevant Google Play account.

9. Security Measures

Studio Monmal uses measures appropriate to the current application architecture, including:

  • Application-private local storage for ordinary app data and attachments
  • No broad storage access permission
  • AES-256-GCM encryption for integrated backup files
  • Password-based key derivation for encrypted backups
  • HTTPS communication with the Telegram Bot API
  • No Studio Monmal user-data collection server
  • No advertising or behavioral analytics SDKs
No method of electronic storage or Internet transmission can guarantee absolute security. Users should protect their device lock, Google account, Telegram Bot Token, and backup passwords.

10. Android Permissions

Line Reminder may use Android permissions for:

  • Posting notifications
  • Scheduling time-sensitive alarms
  • Restoring scheduled notifications after device reboot or time changes
  • Internet access for Telegram Bot API communication

Line Reminder does not use Android Notification Listener permission to read notifications from other applications.

It also does not request permission to read SMS or MMS messages.

11. Data Retention

Information stored by the user within Line Reminder may remain on the device until the user deletes it, clears application data, or uninstalls the application.

Studio Monmal does not retain this information on its own servers.

Backup files exported outside the application may remain at the selected destination until the user deletes them.

Retention of information transmitted to Telegram is governed by Telegram's policies and the user's Telegram configuration.

Google Play purchase information is retained and processed according to Google's policies.

12. Data Deletion

Users may edit or delete information through the functions provided within the application.

Uninstalling Line Reminder or clearing its application data removes locally stored application data according to Android's standard application-data handling.

The following may remain after application removal:

  • Backup files exported by the user
  • Messages previously delivered to Telegram
  • Purchase records maintained by Google Play

These items must be managed through the relevant storage provider, Telegram, or Google Play.

13. Children's Privacy

Line Reminder is not specifically designed as a service directed at children.

The applicable target-audience settings are those declared for the application in Google Play Console.

This Privacy Policy may be updated if application functionality or data-processing practices change.

Important changes may be communicated through this page or application updates, and the "Last updated" date above will be revised.
